Tool Pocket Generator V8

Scaling rule: draw the tool profile freely on the reference frame. The points define the shape. When the profile is closed, V8 scales the profile's bounding box to the exact Length × Width entered. Screen zoom/stretching does not affect the result. Geometry check is run on the scaled profile before clearance and STL export.

6. STL test export
